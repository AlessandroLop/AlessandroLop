## 💡 Proyecto destacado

<div align="center">

### 🧾 DTEVIA / QAPI

**API de facturación electrónica para Guatemala — FEL simplificado**

</div>

Middleware SaaS que abstrae la complejidad del sistema FEL de la SAT detrás de una API REST/JSON moderna, pensado para que cualquier desarrollador guatemalteco pueda emitir facturas electrónicas sin lidiar directamente con XML, certificadores ni la burocracia técnica del sistema.

- 🏗️ Arquitectura backend en **Node.js + TypeScript + Hono**, base de datos en **Supabase (PostgreSQL)**, caché con **Upstash Redis**
- 📄 Pipeline propio de construcción de XML conforme al XSD de la SAT, con validación previa (Zod) antes de enviar al certificador
- 🤝 Integración en curso con certificador autorizado (Grupo CDS / Totaldoc) para firma y timbrado
- 💳 Modelo de precios por pool de facturas (planes Starter / Business)
- ☁️ Desplegado en **Railway**
